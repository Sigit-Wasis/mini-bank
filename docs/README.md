# Mini Bank - Documentation

Selamat datang di dokumentasi proyek **Mini Bank**. Dokumentasi teknis proyek ini dikelola di dalam folder `docs/` guna menjaga keselarasan pemahaman arsitektur, desain sistem, aturan bisnis, serta keamanan aplikasi.

## Daftar Isi Dokumentasi

- **[PRD (Product Requirement Document)](./PRD.md)** - Penjelasan fungsionalitas produk, target pengguna, dan spesifikasi fitur.
- **[DESIGN](./DESIGN.md)** - Panduan rancang bangun antarmuka atau alur interaksi pengguna (UX) & sistem (System Flows).
- **[ARCHITECTURE](./ARCHITECTURE.md)** - Arsitektur sistem (Domain Driven / Clean Architecture) dan pembagian layer (`cmd`, `internal`, `pkg`, dll).
- **[SCHEMA](./SCHEMA.md)** - Skema basis data, ERD, dan penjelasan relasi antar tabel (Postgres).
- **[RULES](./RULES.md)** - Aturan pengembangan kode (Coding conventions), standar kontribus, dan validasi domain perbankan.
- **[API](./API.md)** - Spesifikasi endpoint REST/RPC API (Request, Response, Error Codes).
- **[SECURITY](./SECURITY.md)** - Praktek keamanan sistem perbankan (Autentikasi, Enkripsi, Hashing, Rate Limiting).
- **[DEPLOYMENT](./DEPLOYMENT.md)** - Prosedur deployment untuk staging dan production (Docker, CI/CD, dsb).
- **[TESTING](./TESTING.md)** - Strategi pengujian (Unit Testing, Integration Testing, Mocking).
- **[ROADMAP](./ROADMAP.md)** - Rencana pengembangan fitur jangka pendek dan jangka panjang.
